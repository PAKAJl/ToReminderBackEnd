# Changelog

## [2026-10-22] — Интеграция с фронтендом и исправления

### Исправлено  
- **Инконсистентный парсинг токена (`Bearer`)**: ранее `updateName` (проекты) и `updateTask` сравнивали сырой заголовок Authorization, из-за чего запросы с префиксом `Bearer` молча возвращали `201` + пустой результат. Теперь все контроллеры используют единый хелпер `extractToken` (см. ниже) — `Bearer` корректно вырезается везде.
- **`POST /api/tasks` без токена** падал с 500 (NOT NULL constraint) → теперь `401 Token is required`.
- **`PUT /api/tasks` не сохранял** поля `date` (напоминание) и `color` — добавлены в UPDATE.
- **Некорректные коды ответов**: удаление/обновление несуществующей задачи или чужого токена возвращало `201` + `[]` → теперь `404 Task not found`; отсутствие `id` → `400`.
- Удалены отладочные `console.log` из контроллеров и сервисов.

### Добавлено
- `src/utils/extractToken.js` — единая нормализация заголовка `Authorization` (с/без `Bearer`).
- Поля `color` (text, по умолчанию `white`) и `created_at` (integer, ms) в таблицу `tasks` (схема + push в БД) — нужны фронтенду для цвета карточек и даты создания.

### Изменено
- `PUT /api/tasks` и `GET /api/projects/delete` при успехе возвращают `200` (было `201`).
